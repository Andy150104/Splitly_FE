# Navbar Olive Glass V5

## Direction

The old full-width editorial header is replaced by a centered floating capsule inspired by the supplied reference, but translated into the mơ. visual system instead of copied literally.

- Olive translucent glass rather than pure black.
- Cream CTA for contrast with the wallet / savings palette.
- Soft 22px background blur, thin luminous border and restrained shadow.
- Compact `mơ.` brand capsule inside the main capsule.
- Active section marker follows Home / Explore / Dreams as the story is scrolled.
- Header subtly tightens after the page starts scrolling instead of jumping or changing layout.
- Mobile keeps the same glass material and opens a floating rounded menu rather than a full-width sheet.

## Layout QA targets

- Desktop: navbar remains centered and under 72% of viewport width.
- Phone: 10–14px side breathing room and zero document horizontal overflow.
- Hero remains pinned below the reserved transparent header space, so the 3D story is not hidden under navigation.
- Reduced-motion users receive the same layout with navigation transitions disabled.
